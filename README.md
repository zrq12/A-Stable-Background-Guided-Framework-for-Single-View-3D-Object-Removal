# A Stable-Background-Guided Framework for Single-View 3D Object Removal

Repository accompanying the paper **A Stable-Background-Guided Framework for Single-View 3D Object Removal**.

## Code availability

The code for this paper will be released in this repository upon acceptance.

## Datasets

The experiments use the following third-party datasets. Please obtain the data from the original providers and follow their access requirements and terms of use.

| Dataset | Original source |
| --- | --- |
| OBER | [Official ObjectClear dataset release](https://huggingface.co/datasets/sczhou/OBERDataset_ObjectClear) |
| RORD | [RORD project repository](https://github.com/IIDA-AILab/RORD) |
| SUN RGB-D | [SUN RGB-D benchmark website](https://rgbd.cs.princeton.edu/) |

The datasets remain the property of their respective providers and are not redistributed in this repository. Please cite the corresponding dataset papers when using them.
